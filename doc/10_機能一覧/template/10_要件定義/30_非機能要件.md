| 粒度（TRACE/DEBUG/INFO/WARN/ERROR） | 内容の例 |
|---------------------------------------|----------------|
| TRACE | 詳細な処理の流れや変数の値 |
| DEBUG | 開発者向けのデバッグ情報 |
| INFO | ユーザーの操作やシステムの重要なイベント |
| WARN | パフォーマンスの低下やリソースの不足、業務継続に影響のない異常 |
| ERROR | システムエラーや例外 |
