- `doc\10_業務一覧\template\30_機能一覧\template`をコピーして、新規機能フォルダーを作成すること。
- 新規機能フォルダーは、`doc\10_業務一覧\業務コード_業務名\30_機能一覧`直下に作成すること。
    - `業務コード_業務名`の部分は、機能が属する業務のコードと名称に置き換えること。
- 新規機能フォルダー名は、`サブシステムコード_機能名`の形式とすること。
   - サブシステムコードは、既存のサブシステムコードと重複しない1桁の英数字とすること。
   - 機能名は、わかりやすく簡潔な日本語とすること。
- サブシステムコードは`doc\10_業務一覧\業務コード_業務名\30_機能一覧\10_サブシステム一覧.md`に追記すること。
    - `業務コード_業務名`の部分は、機能が属する業務のコードと名称に置き換えること。
