# requirements

要件定義工程（What）を管理するディレクトリです。

## 配下ディレクトリ
- `system_overviews/`: システム全体概要
- `nonfunctional_requirements/`: 非機能要件
- `glossaries/`: 用語定義
- `business_codes/`: 業務コード定義
- `business_flows/`: 業務フロー図
- `functional_requirements/`: 機能要件

## 進め方
1. 全体前提（概要/非機能/用語/業務コード）を確定
2. 業務フローを作成
3. 機能要件を作成
